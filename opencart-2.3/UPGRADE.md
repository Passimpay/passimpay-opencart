# PassimPay для OpenCart 2.3 — 2.3-p.8

1. Сохраните резервную копию файлов модуля и базы магазина.
2. Скопируйте содержимое `upload/` из `passimpay-opencart-2.3.zip` в корень OpenCart. При обновлении замените файлы, не удаляя модуль и его таблицы. Не устанавливайте существующий модуль повторно кнопкой Install: она сбрасывает настройки.
3. При первой установке установите PassimPay в разделе способов оплаты. Укажите API Key и Platform ID. Тип оплаты: `0` — карта и криптовалюта, `1` — криптовалюта, `2` — карта. Отдельный способ PassimPay Card использует общие ключи. Карты должны быть включены в проекте PassimPay.
4. В проекте PassimPay укажите Notification URL: `https://shop.example/index.php?route=extension/payment/passimpay/callback`.
5. Адрес возврата: `https://shop.example/index.php?route=extension/payment/passimpay/callback_return`. Учитывайте подкаталог магазина.
6. В Allowed IPs используйте подтверждённые адреса отправителей PassimPay. При работе через reverse proxy настройте доверенную передачу реального IP на сервере; модуль проверяет `REMOTE_ADDR`.
7. Проверьте создание счёта, оплату и возврат покупателя. Нужны PHP cURL и исходящий HTTPS к `https://api.passimpay.io`.

API v2 используется автоматически. Валюта и сумма счёта берутся из заказа. Поздний платёж или платёж с отличающейся суммой может потребовать ручной сверки; проверьте историю заказа. При обновлении сохраняйте данные о ранее выставленных счетах.

Статус оплаты определяется серверной проверкой платежа. Адрес уведомлений должен принимать POST JSON и заголовок `x-signature` без перенаправлений и проверок браузера. Актуальные IP-адреса отправителей для настройки сервера получите у [поддержки PassimPay](https://passimpay.io/en/contacts); требования описаны в [документации уведомлений](https://passimpay.gitbook.io/passimpay-api/webhook).

Platform ID и API Key доступны в настройках проекта в [кабинете PassimPay](https://account.passimpay.io/).
